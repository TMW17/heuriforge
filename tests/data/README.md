`X-n101-k25.vrp` and `X-n101-k25.sol` are one instance of the CVRPLIB set X
(Uchoa, Pecin, Pessoa, Poggi, Subramanian and Vidal, 2017) with its best-known solution,
as distributed in https://github.com/PyVRP/Instances (MIT license). The tests use it to
check that costs are recomputed exactly like the published best-known solutions.
